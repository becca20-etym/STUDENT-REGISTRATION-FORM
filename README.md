# Student Registration Form

## About the Project
This project is a simple student registration form built with HTML. It provides a structured way to collect basic information through input fields and a submit button.

## What I Practised
- Creating HTML forms.
- Using input fields and different input types.
- Adding labels and placeholders.
- Creating buttons.
- Nesting HTML elements correctly.
- Structuring a webpage using HTML5.

## Technologies Used
- HTML5

## What I Learned
I learned how input elements and buttons contribute to a form's structure. I also gained a better understanding of HTML attributes and the importance of providing clear labels for form fields.

## How to View the Project
Open form.html in a web browser.

## Current Limitations
This is a static HTML project. It does not currently process form submissions or store user information.

## Future Improvements
- Use CSS to style the form.
- Add appropriate form validation.
- Explore JavaScript for interactive behaviour.
- Learn how form data can be processed securely.
